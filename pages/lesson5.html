LESSON 05

ගිණුම්කරණ සමීකරණය

ව්‍යාපාරයක වත්කම්, වගකීම් සහ හිමිකම අතර සම්බන්ධතාවය හඳුනා ගනිමු.

📘 5.1 ගිණුම්කරණ සමීකරණය යනු කුමක්ද?

ව්‍යාපාරයක සම්පත් හෙවත් වත්කම් සඳහා මුදල් සපයා ඇති මූලාශ්‍ර අතර සම්බන්ධතාවය ගණිතමය ආකාරයෙන් දැක්වීම ගිණුම්කරණ සමීකරණය ලෙස හැඳින්වේ.

වත්කම් = හිමිකම + වගකීම්

💰 5.2 වත්කම්

ව්‍යාපාරයට අයත් ආර්ථික වටිනාකමක් ඇති සම්පත් වත්කම් ලෙස හැඳින්වේ.

උදාහරණ

  • මුදල්
  • බැංකු තැන්පතු
  • තොග
  • ගොඩනැගිලි
  • යන්ත්‍රෝපකරණ
  • ගෘහ භාණ්ඩ

📌 5.3 වගකීම්

ව්‍යාපාරය වෙනත් පාර්ශ්වයන්ට ගෙවිය යුතු මුදල් හෝ පියවිය යුතු බැඳීම් වගකීම් ලෙස හැඳින්වේ.

උදාහරණ

  • වෙළෙඳ ගෙවිය යුතු
  • බැංකු ණය
  • වෙනත් ණය

👤 5.4 හිමිකම

ව්‍යාපාරයේ වත්කම්වලින් වගකීම් ඉවත් කළ පසු හිමිකරුට අයත් ඉතිරි කොටස හිමිකම ලෙස හැඳින්වේ.

හිමිකම = වත්කම් − වගකීම්

⚖️ 5.5 ගිණුම්කරණ සමීකරණය

වත්කම් = හිමිකම + වගකීම්

මෙම සමීකරණයේ දෙපසම සමාන වටිනාකමක් පවත්වා ගත යුතුය.

එබැවින් ව්‍යාපාරයක සිදුවන සෑම ගනුදෙනුවක්ම ගිණුම්කරණ සමීකරණයේ සමතුලිතතාවයට බලපාන ආකාරයෙන් සලකා බැලිය යුතුය.

🧮 5.6 උදාහරණය 01

ක්‍රිෂාන් විසින් ව්‍යාපාරයක් ආරම්භ කිරීම සඳහා රු. 100,000 ක මුදලක් යොදවයි.

මෙහිදී ව්‍යාපාරයට ලැබුණු වත්කම = රු. 100,000

හිමිකම = රු. 100,000

වගකීම් = රු. 0

වත්කම් හිමිකම වගකීම්
රු. 100,000 රු. 100,000 රු. 0

🧮 5.7 උදාහරණය 02

ව්‍යාපාරය රු. 50,000 ක බැංකු ණයක් ලබා ගනී.

ව්‍යාපාරයේ වත්කම් රු. 50,000 කින් වැඩි වේ.

එම අවස්ථාවේදී වගකීම් ද රු. 50,000 කින් වැඩි වේ.

වත්කම් හිමිකම වගකීම්
රු. 150,000 රු. 100,000 රු. 50,000
150,000 = 100,000 + 50,000

🔄 5.8 ගනුදෙනු ගිණුම්කරණ සමීකරණයට බලපාන ආකාරය

ව්‍යාපාරයේ සිදුවන ගනුදෙනුවක් නිසා වත්කම්, වගකීම් හෝ හිමිකම වෙනස් විය හැක.

උදාහරණ:

ව්‍යාපාරය රු. 20,000 ක භාණ්ඩ මුදලට මිලදී ගනී.

මුදල් වත්කම අඩු වන අතර තොග වත්කම වැඩි වේ.

එබැවින් සමස්ත වත්කම් වටිනාකම වෙනස් නොවේ.

📈 5.9 හිමිකම වෙනස් වන අවස්ථා

ව්‍යාපාරයේ ආදායම් හා වියදම් වැනි සිදුවීම් හිමිකමට බලපෑම් කළ හැක.

අමතර ප්‍රාග්ධනයක් යෙදීම → හිමිකම වැඩි වීමට බලපායි.

ගැනිලි → හිමිකම අඩු වීමට බලපායි.

ආදායම් → හිමිකම වැඩි වීමට බලපායි.

වියදම් → හිමිකම අඩු වීමට බලපායි.

📝 5.10 පාඩමේ සාරාංශය

  • වත්කම් = හිමිකම + වගකීම්
  • හිමිකම = වත්කම් − වගකීම්
  • ව්‍යාපාර ගනුදෙනු ගිණුම්කරණ සමීකරණයට බලපායි.
  • සමීකරණයේ දෙපස සමාන වටිනාකමක් පවත්වා ගත යුතුය.
  • ආදායම් සහ වියදම් හිමිකමට බලපායි.

📝 ක්‍රියාකාරකම් 10

  1. වත්කම් රු. 100,000ක් සහ වගකීම් රු. 30,000ක් නම් හිමිකම සොයන්න.
    පිළිතුර:
    හිමිකම = වත්කම් − වගකීම්
    = 100,000 − 30,000
    හිමිකම = රු. 70,000
  2. හිමිකම රු. 80,000ක් සහ වගකීම් රු. 20,000ක් නම් වත්කම් සොයන්න.
    පිළිතුර:
    වත්කම් = හිමිකම + වගකීම්
    = 80,000 + 20,000
    වත්කම් = රු. 100,000
  3. ව්‍යාපාරයක් රු. 150,000ක මුදලක් යොදා ආරම්භ කරන ලදී. මෙම ගනුදෙනුව ගිණුම්කරණ සමීකරණයට බලපාන ආකාරය දක්වන්න.
    පිළිතුර:
    වත්කම් + රු. 150,000
    හිමිකම + රු. 150,000
    වගකීම් = රු. 0

    150,000 = 150,000 + 0
  4. ව්‍යාපාරය රු. 50,000ක බැංකු ණයක් ලබා ගත්තේ නම් ගිණුම්කරණ සමීකරණයේ සිදුවන වෙනස්කම් දක්වන්න.
    පිළිතුර:
    වත්කම් + රු. 50,000
    වගකීම් + රු. 50,000
    හිමිකම වෙනස් නොවේ.

    150,000 + 50,000 = 150,000 + 50,000
  5. ව්‍යාපාරය රු. 20,000ක භාණ්ඩ මුදලට මිලදී ගත්තේ නම් වත්කම්වල සිදුවන වෙනස පැහැදිලි කරන්න.
    පිළිතුර:
    මුදල් වත්කම රු. 20,000කින් අඩු වේ.
    තොග වත්කම රු. 20,000කින් වැඩි වේ.
    සමස්ත වත්කම් වටිනාකම වෙනස් නොවේ.
  6. වත්කම් රු. 200,000ක් සහ හිමිකම රු. 140,000ක් නම් වගකීම් සොයන්න.
    පිළිතුර:
    වගකීම් = වත්කම් − හිමිකම
    = 200,000 − 140,000
    වගකීම් = රු. 60,000
  7. පහත අයිතම වත්කම්, වගකීම් හෝ හිමිකම ලෙස වර්ගීකරණය කරන්න: මුදල්, බැංකු ණය, තොග, ගොඩනැගිලි, වෙළෙඳ ගෙවිය යුතු.
    පිළිතුර:
    වත්කම්: මුදල්, තොග, ගොඩනැගිලි.
    වගකීම්: බැංකු ණය, වෙළෙඳ ගෙවිය යුතු.
    මෙම ප්‍රශ්නයේ හිමිකමට අදාළ අයිතමයක් ලබා දී නැත.
  8. ආරම්භක වත්කම් රු. 300,000කි. වගකීම් රු. 80,000කි. ව්‍යාපාරය රු. 40,000ක ආදායමක් උපයා රු. 15,000ක වියදමක් දැරීය. අවසාන හිමිකම සොයන්න.
    පිළිතුර:
    ආරම්භක හිමිකම = 300,000 − 80,000 = රු. 220,000

    ආදායම නිසා හිමිකම වැඩි වේ: 220,000 + 40,000 = රු. 260,000

    වියදම නිසා හිමිකම අඩු වේ: 260,000 − 15,000 = රු. 245,000
  9. ව්‍යාපාරයක වත්කම් රු. 500,000ක් සහ වගකීම් රු. 180,000ක් වේ. ව්‍යාපාරය රු. 50,000ක බැංකු ණයක් ලබා ගත්තේ නම් නව වත්කම්, වගකීම් සහ හිමිකම සොයන්න.

    නව වත්කම් = 500,000 + 50,000 = රු. 550,000
    නව වගකීම් = 180,000 + 50,000 = රු. 230,000
    හිමිකම = රු. 320,000

  10. පහත ගනුදෙනු අනුපිළිවෙළින් සලකා සෑම ගනුදෙනුවකටම පසු ගිණුම්කරණ සමීකරණය සකස් කරන්න.

    1. හිමිකරු රු. 200,000ක් මුදලින් යොදවයි.
    2. රු. 50,000ක බැංකු ණයක් ලබා ගනී.
    3. රු. 30,000ක භාණ්ඩ මුදලට මිලදී ගනී.
    4. රු. 20,000ක ආදායමක් උපයයි.
    5. රු. 5,000ක වියදමක් ගෙවයි.

    4. ආදායම නිසා හිමිකම 20,000කින් වැඩි වේ: 270,000 = 220,000 + 50,000
